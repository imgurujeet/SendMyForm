## 📚 3. Documentation (The easyForm Protocol)

### 🚀 Quick Start
1.  **Sign In:** Auth with Google in one click.
2.  **Define Slug:** Create a unique endpoint like `/api/f/contact-us`.
3.  **Choose Theme:** Select from 4 premium email designs.
4.  **Connect Form:** 
    ```html
    <form action="http://localhost:3000/api/f/my-slug" method="POST">
      <input name="email" type="email" />
      <button type="submit">Submit</button>
    </form>
    ```

### 👨‍💻 For Businesses & Agents
*   **Centralized Leads:** Manage multiple client forms from one studio.
*   **Zero Maintenance:** No need to manage SMTP or server-side scripts for every client site.
